# Unofficial Autodesk Inventor API package

This package holds one Autodesk Inventor or iLogic API assembly, with its XML documentation when Autodesk
supplies it.

- **Unofficial.** This project is not affiliated with, endorsed by, or sponsored by Autodesk.
- **Compile time only.** The files are under `ref/`. Nothing is copied to your output folder, because Inventor
	supplies these assemblies at run time.
- **Version.** `<product year>.<update>.<patch>`, ex. `2027.2.0`.
- **License.** Read `NOTICE.md` in this package. The assemblies and their documentation are Autodesk files.

```xml
<PackageReference Include="TylerWarner33.Inventor.Api.Interop" Version="2027.*" />
```
